# filmsok-site

Publiseringsrepo for [filmsok.no](https://filmsok.no).

Dette repoet inneholder bare en GitHub Actions-workflow. Den henter koden fra et
privat repo, bygger siden hver natt og publiserer den med GitHub Pages.

## Attribusjon

This website uses TMDB and the TMDB APIs but is not endorsed, certified,
or otherwise approved by TMDB.

Strømmetilgjengelighet leveres av [JustWatch](https://www.justwatch.com)
gjennom TMDB.
